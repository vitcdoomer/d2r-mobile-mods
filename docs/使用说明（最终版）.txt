【D2R Mobile 增强版 · 使用说明（最终版）】
安装包：D2RMobile-v1.0.16-arrow1g-cheat1o.ipa
日期：2026-10-18
================================================================

本说明对应最终版，只描述"现在怎么用"。开发过程中的逐版本修复记录已全部移除。


一、这个包是什么
----------------------------------------------------------------
在 d2r-mobile 壳（v1.0.16）基础上，注入了三个模块：

  1) 任务路径箭头 —— 人物旁一个箭头，指向本关任务终点；任务做完指小站
  2) 金手指面板   —— 属性 / 收益 / 关卡传送 / 技能键长按移除 / 按钮可拖动
  3) 存档一键搬家 —— 存档打包进「文件」App，换设备一键导入

爆率与怪物密度已经写进游戏数据文件，随包生效，面板中只做只读显示：
    暗金 40% · 绿色 40% · 黄金（稀有）10% · 蓝装 6% · 白装约 4% · 怪物密度 ×4


二、安装（三步）
----------------------------------------------------------------
第 1 步 签名装机
  · 电脑装 Sideloadly（或 AltStore）
  · 载入本 IPA，用你自己的 Apple ID 自签安装（免费账号即可）
  · 手机上「设置 → 通用 → VPN 与设备管理」点一次信任
  · 免费账号 7 天过期，到期重签重装（存档不会丢）

第 2 步 拷游戏资源
  · 把 phone-resource\游戏资源\ 里的 .data 文件拷进手机
  · iPhone 连电脑 → Finder 选中手机 → 文件页签 → 找到 App → 拖进去
  · 也可在手机「文件」App 里操作

第 3 步 首次启动
  · 打开 App → 点「重试」→ 等待着色器准备（首次约 7 分钟，建议插电）
  · 进主菜单后即可正常游玩


三、金手指面板
----------------------------------------------------------------
【打开 / 收起】
  点左上角「金手指」按钮。按住按钮可拖动到任意位置，松手即记住，
  下次启动还在原处（位置存 Documents/dmcheat.pos）。轻点仍是开/关面板。

【属性】剩余属性点 / 剩余技能点 / 跑速 / 攻速 / 施法速度 / 全技能
  · 加减号调节，即时生效，退出面板仍然有效
  · 属性点上限 5000（步进 50）· 技能点上限 1000（步进 10）
  · 跑速 / 攻速 / 施法速度为百分比（上限 300%，步进 5，默认 100 = 原速）
  · 全技能为加几级（上限 +50）

【收益】经验获取 / 金钱获取
  · 倍率制，1~10 倍，1 = 原版

【掉落】暗金 40% · 绿色 40% · 黄金 10% · 蓝装 6%（白装约 4%）· 密度 ×4
  · 已写进游戏数据文件，面板只读显示，改档位需要重新出包
  · 黄金装备即「稀有（黄色）」装备
  · 品质按 暗金 → 绿色 → 黄金 → 蓝装 顺序判定，以上为期望占比

【总开关】
  · 关掉 = 还原所有运行时修改（属性、收益、传送）
  · 内置的数据表（爆率 / 密度）不受总开关影响

【关卡传送】
  选关卡号（加减号）→ 点「传送」；或直接点 8 个快捷点：
    罗格营地 / 鲁高因 / 库拉斯特 / 群魔堡垒
    混沌避难所 / 哈洛加斯 / 亚瑞特之巅 / 世界之石
  · 立即生效，但建议回到安全区再传，避免正在战斗中被打断

【技能键：长按 3 秒移除】
  1) 单指按住要移除技能的按钮（主技能大钮或 F1~F4）约 3 秒
  2) 弹出「移除该技能？」→ 点【移除】
  3) 该键变成空位（单色十字）
  4) 想重新绑：直接点那个十字 → 自动打开技能树 → 点新技能即绑上
  · 长按时请只留一根手指：另一根推摇杆会取消 iOS 的长按识别
  · 弹框会中断这一次按住的施放，属正常现象
  · 本来就空的技能位，长按不会弹框


四、存档搬家（iPhone ↔ iPad）
----------------------------------------------------------------
【入口】
  主菜单 / 人物选择页左上角「存档」按钮 →「存档搬家」小面板
  · 进入关卡后按钮自动隐藏（避免游戏运行中读写存档）
  · 退回主菜单会重新出现
  · 导出 / 导入前请先正常退到主菜单

【导出】
  1) 点【导出存档】→ 后台打包成 D2Rsave-日期-时间.zip
  2) 约 1~2 秒后弹窗告诉文件名
  3) 打开「文件」App → D2R Mobile → 长按该文件 → 拷贝 → 选 iCloud Drive

【导入】
  1) 在源设备导出后，把 zip 放进目标设备：「文件」App → iCloud Drive →
     长按 zip → 拷贝 → 目标选 D2R Mobile
  2) 目标设备回游戏 →「存档」→【导入存档】→ 弹窗列出找到的包
  3) 选一个 → 自动把旧档备份为 save_backup-日期-时间 → 解压覆盖
  4) 彻底关闭 App（上滑杀掉）再重新打开，才算生效

【注意】
  · 导入后到重启前，不要回游戏继续玩
  · 解压失败会自动回滚，原存档不受影响
  · 不依赖 App 的 iCloud 权限（全程走「文件」App 手动搬运）
  · 存档包是 stored（不压缩）的 zip，电脑上可直接打开查看
  · 旧存档包不会自动删除，需要空间时自己在「文件」App 里清


五、任务路径箭头
----------------------------------------------------------------
【两种颜色】
  金色 = 本关任务终点（同屏多个时取最近的那个）
  蓝色 = 本关没有任务目标（任务已做完等），改指本关小站
  两者都没有（少数地城）→ 不显示箭头

【行为】
  · 悬浮在人物旁固定距离，跟着人物走并旋转指向目标
  · 走近目标自动隐藏
  · 只画一个主箭头，不会满屏都是


六、配置文件一览（都在「文件」App → D2R Mobile 下）
----------------------------------------------------------------
  dmcheat.txt    金手指设置（面板会自动写，也可手改后重启生效）
                 键：master / stat_points / skill_points / run / ias /
                     fcr / skills / exp / gold
  dmcheat.pos    金手指按钮位置，一行 "x,y"；删掉即恢复左上角默认
  dmarrow.cfg    箭头设置（首次运行自动生成）
                 on=1            总开关
                 mode=player     人物旁悬浮（edge = 旧贴边样式）
                 size=26         箭头大小
                 offset=46       离人物脚底的距离
                 hide_near=6     走近多少格隐藏
                 fps=30          刷新率
                 wp_fallback=1   没有任务目标时指小站（0 = 关掉）
                 origin=player   原点取玩家脚下（center = 画面中心）
                 hide_map_full=1 全屏地图时隐藏
  dmcheat.log    金手指日志
  dmarrow.log    箭头日志
  dmsave.log     存档导出/导入日志


七、已知限制
----------------------------------------------------------------
  · 仅离线角色：所有修改都是本地行为，不涉及战网
  · 爆率 / 密度改档位需重新出包（构建期写入，不是运行时开关）
  · 存档导入后必须彻底关闭 App 再打开
  · 长按移除技能在多指操作时可能不触发（iOS 手势取消）
  · 箭头只指向壳能识别的任务物件，非任务类目标不显示
  · 壳升级后游戏内符号地址会变，注入库需要重新构建


八、故障速查
----------------------------------------------------------------
  现象                          先看这里
  ----------------------------  ------------------------------------
  金手指按钮不见了              按钮可能被拖到屏幕边缘：删掉 dmcheat.pos
                                后重启 App，恢复左上角默认位置
  面板点了没反应                看 dmcheat.log 最后几行
  属性改了没效果                确认总开关是开的；面板上方提示行是否报错
  传送没反应                    要在关卡内使用（主菜单无法传送）
  长按技能 3 秒不弹框           确认单指按住；看 dmcheat.log 是否有
                                「找到触摸视图 …识别器已挂上」
  箭头不显示                    本关既无任务终点也无小站；检查 dmarrow.cfg
                                里 on=1
  导出点了没反应                看 dmsave.log 是否出现「打包完成（N 个文件）」
  导入报错                      dmsave.log 会写明失败环节与错误码
  App 闪退后能正常重开          多为内存压力，记下当时在做什么；连续发生
                                请把三个 .log 一并保留

  日志位置：「文件」App → D2R Mobile → 对应 .log
  排查问题时把日志发出来即可定位，不需要截图。
